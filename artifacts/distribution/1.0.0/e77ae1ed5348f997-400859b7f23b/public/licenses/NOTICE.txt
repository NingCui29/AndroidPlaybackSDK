AndroidPlaybackSDK includes unmodified FFmpeg 8.1.3 shared libraries from the FFmpeg project.
The configuration used for these binaries reports LGPL version 2.1 or later.
The accompanying FFmpeg-LGPL-2.1.txt and FFmpeg-LICENSE.md come from the same official source archive.
Source: https://ffmpeg.org/releases/ffmpeg-8.1.3.tar.xz
Archive SHA-256: 7138d28c96d9d3e3af4ee3d8cad72741f8ffb40da90c1112235dea3ecd3178a3
Build inputs and component selection: tools/build-ffmpeg.sh in the accompanying SDK sources.
The five FFmpeg libraries are dynamically linked. The SDK has no external Java runtime dependencies.
