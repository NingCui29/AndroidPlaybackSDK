# SDK 接入契约

七项契约于 2026-11-11 经用户确认，适用于独立 Android 库。公开包名为 `com.cn.media.playback`。Java/Kotlin 共用 Player、监听器、请求编号及不可变快照；公开时间为毫秒，未知时长可空。默认主线程回调，可指定 Executor，SDK 保证同实例串行交付。

播放进度默认每 250 ms 推送，可设 100～1000 ms，0 关闭周期推送。关键事件立即排入回调队列。实例线性音量范围 0.0～1.0，默认 1.0，静音独立，非法值拒绝并保留原值。

错误码采用 [A03 已确认编号表](09-api-review.md)，取消与取代属于命令结果。每实例仅在内存保留最近 128 条脱敏诊断，释放时清除。天然单轨正常播放；双轨部分失败默认上报降级并继续可播轨，可选严格模式。仅硬解模式遵守显式后端约束；双轨必播样本的单轨降级不能计为格式验收通过。

## 对象与所有权

| 对象 | 责任与有效期 |
|---|---|
| PlayerConfig | 创建实例时固定，定义解码策略、回调执行器、日志级别、队列预算及 Surface 缺失策略 |
| Player | 代表一个可复用播放实例。各实例有独立会话和时钟；创建时只持有应用上下文 |
| MediaSource | 文件、content URI 或描述符区间。调用时复制外部描述符，复制成功后调用方即可关闭原件；复制失败同步反馈 |
| MediaInfo / TrackInfo | 不可变媒体快照，含时长、是否可定位、编码、语言、旋转、声道及轨道 ID；轨道 ID 在一次打开期间有效 |
| PlayerSnapshot | 最近一次一致的状态，包含会话编号、主状态、播放意图、位置、选轨、缓冲和定位标记 |
| Surface | 由宿主创建和销毁，SDK 只释放自己的引用；支持无 Surface 的音频实例 |

## 命令与事件

公开命令可从宿主线程调用。短暂参数检查后排入串行控制队列。每个异步请求有编号，并得到成功、失败或被后续请求取代的结果。所有时长和位置在公开 API 中使用毫秒，时长未知单独表达。默认在主线程分发事件，可注入串行执行器。监听器可发起下一条命令；避免持有引擎锁执行宿主回调。

| 命令 | 语义 |
|---|---|
| open | 切源时取消旧请求、清空旧媒体状态，异步探测并准备所选轨道；默认准备后停在 Ready |
| play / pause | 设置播放意图；准备或定位期间保留最后意图。Ended 状态重播要求输入可重新打开或定位 |
| seekTo | 目标限制在有效范围内。可定位时报告实际落点；顺序输入返回不可定位。连续请求仅执行最新待处理目标 |
| selectAudioTrack | 先验证新轨，利用可用解码参数准备后端，再切换输出。不能保持原轨时明确报告当前选轨和失败状态 |
| setVideoSurface | 绑定或解绑输出并提供完成通知；旧 Surface 解绑完成后播放器不再访问它 |
| setVolume / setMuted | 音量作用于当前实例；静音保留音频时钟，恢复时沿用静音前音量 |
| stop / release | stop 完成后回到 Idle，可再次 open。release 可重复调用；完成时工作线程及本会话 native 资源已退出 |

## 状态与事件顺序

主路径为 Idle → Preparing → Ready → Playing → Ended。Playing 可进入 Paused，恢复后回 Playing。准备失败进入 Error，可用 open 恢复。stop 可打断准备和播放，release 终结实例。暂停、定位、换轨均保留已选媒体。缓冲中和定位中作为附加状态，可与暂停意图并存。

准备完成交付轨道清单，音频开始计数及视频首帧提交单独报告。首帧提交指提交到有效输出，无法据此保证屏幕已实际显示。每个打开请求最多一次终止结果。旧会话的进度、首帧、错误不得覆盖新会话。释放完成为最后一次生命周期通知。

## 宿主责任与可诊断错误

宿主处理媒体读取授权、音频焦点、页面与后台策略，选择 SurfaceView 或 TextureView 并通知输出变化。SDK 核心不要求绑定 Activity、播放器控件或服务。Java 接入使用回调和不可变快照，无需在公开接口中暴露协程或 native 指针。

错误携带阶段、会话编号、稳定错误码、原始后端错误及可恢复性。分别标识权限拒绝、输入不可读、不可定位、封装不支持、轨道不支持、解码失败、资源不足和输出失效。取消和请求被取代属于操作结果。默认诊断只记录媒体技术参数、后端名和失败阶段，避免输出私人路径或带凭据的 URI。
